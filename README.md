The Passport Page of a Country That Isn't There: a program that writes an invented passport spread to `/output/entry.png` — the data page of Mara Ellison Voss, cartographer of the Republic of Valdoria (portrait, personal details, machine-readable zone), beside a visas page with a Kestrelia visa, four matching entry/exit stamp pairs, and a customs declaration for 2 kg of Meridian coffee beans. Every stamp, date and detail agrees with the others.

## Run it

```sh
python3 main.py
```
